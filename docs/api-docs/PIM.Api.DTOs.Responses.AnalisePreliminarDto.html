Remarks

Retornado pelo endpoint POST /api/ia/analisar-preliminar. Contém sugestões da IA (GPT-3.5-turbo) para categorização, priorização e resolução do problema. O usuário pode aceitar as sugestões ou modificá-las antes de criar o chamado.
